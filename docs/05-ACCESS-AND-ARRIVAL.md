# 5. Gates, codes, doors, and access

[README](../README.md) | Prev: [4. Places, steps, and labels](04-PLACES-STEPS-LABELS.md) | Next: [6. Examples](06-EXAMPLES.md)

---

Many real arrivals fail because access details are not part of the map.

Hashpath should support instructions such as:

- gate code
- door code
- buzzer name
- call box instruction
- after-hours entrance
- delivery dock
- no-parking warning
- locked gate warning
- alternate entrance
- “do not use GPS after this point”
- “turn before the sign”
- “road closed after rain”

## Non-spatial payloads

Some instructions are not locations.

A gate code is not a point.

A buzzer name is not a point.

A warning is not a point.

Hashpath needs to carry these without pretending they are coordinates.
