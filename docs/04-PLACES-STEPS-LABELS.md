# 4. Places, steps, and labels

Hashpath needs labels because the same physical point can mean different things in an arrival procedure.

A point can be:

- gate
- parking
- lobby
- stairs
- elevator
- door
- dock
- pickup
- dropoff
- office
- mailbox
- front desk
- fallback route

Labels let the procedure distinguish the role of the point.

## Spatial vs procedural meaning

A coordinate tells software where something is.

A label tells the human or agent what to do with that point.

Example:

```text
parking != entrance != door != pickup point
```

Even when these are near each other, they are not interchangeable.
