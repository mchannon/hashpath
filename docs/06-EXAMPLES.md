## Apartment delivery

```text
Gate → code → visitor parking → stairs → door
```

Useful details:

```text
Use west gate.
Enter 4729.
Park in visitor row.
Stairs are behind Building C.
Door is upstairs on the left.
```

## Rideshare pickup

```text
Entrance → pickup point → fallback point
```

Useful details:

```text
Do not stop on the main road.
Use the hotel side entrance.
Pickup is at the blue awning.
If blocked, use the rear lot.
```

## Rural delivery

```text
Driveway → fork → gate → drop point
```

Useful details:

```text
GPS will stop early.
Take the left fork after the cattle guard.
Close the gate.
Leave package in the metal box by the pump house.
```

## Event venue

```text
Parking → pedestrian gate → check-in → room
```

Useful details:

```text
Use Lot B.
Do not use the main entrance.
Check in at the volunteer table.
Room is upstairs, north hallway.
```
