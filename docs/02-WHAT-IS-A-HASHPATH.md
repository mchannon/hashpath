# 2. What a Hashpath is

[README](../README.md) | Prev: [1. Why Hashpath?](01-WHY-HASHPATH.md) | Next: [3. Format and segments](03-FORMAT-AND-SEGMENTS.md)

---

A Hashpath is a compact, structured arrival instruction.

It can include:

- waypoints
- access codes
- parking instructions
- gates
- doors
- stairs
- elevators
- dropoff points
- pickup points
- fallback instructions
- warnings
- local anchors
- short human notes

A simple Hashsite-style point says:

```text
go here
```

A Hashpath says:

```text
go here, then do this, then use that entrance, then finish here
```

## Hashpath is an app/product

Hashpath is not merely a “grammar” sitting underneath Hashsite.

Hashpath is its own app/product and documentation site.

Its object is the arrival procedure.

Hashsite’s object is the compact place code.

They can work together, but neither is merely a footnote to the other.
