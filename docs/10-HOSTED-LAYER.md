# 10. Hosted layer and publishing

---

Some Hashpaths can be fully contained in a compact string.

Others may need a hosted layer.

A hosted layer can support:

- longer notes
- private access details
- expiration
- revocation
- updates
- permissions
- attachments
- images
- QR codes
- venue-managed arrival instructions

## Public vs private

A public Hashpath might describe how to reach an event entrance.

A private Hashpath might include a gate code, lockbox code, or staff-only route.

The format should support both without confusing them.
